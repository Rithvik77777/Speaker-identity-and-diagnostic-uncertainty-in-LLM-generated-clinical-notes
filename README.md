# Speaker identity and diagnostic uncertainty in LLM-generated clinical notes

Does an LLM writing a clinical note treat the same uncertain diagnostic statement differently when it is attributed to the doctor vs. the patient?

## Contents
- [`primock57_replication/`](primock57_replication/) (Hang Zhao) — the replication on PriMock57. It contains the data, code, 912 generations from three open-weight models (Qwen3-4B, Phi-4-mini, Granite-4.0-micro), two-rater human labels, the final E1–E4 tables and figures, and paper-ready text. **Start with [`primock57_replication/README.md`](primock57_replication/README.md) §2, "How to use these results".**
